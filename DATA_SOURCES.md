# Data sources and attribution

The code in this repository is under the MIT License (see LICENSE). The case data is built from
the sources below, each under its own terms.

- **Companies House** (company records, officers, persons with significant control, filing
  history, disqualified directors). Contains public sector information licensed under the
  [Open Government Licence v3.0](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/).
- **The Insolvency Service and The Gazette** (public-interest winding-up outcomes). Contains public
  sector information licensed under the Open Government Licence v3.0.
- **Financial Conduct Authority register.** Contains public sector information licensed under the
  Open Government Licence v3.0.
- **UK Sanctions List** (FCDO) and the **OFAC SDN list** (US Treasury), public lists.
- **Wikidata** (politically exposed persons), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
- **Web evidence:** Google search result links (via SerpAPI) and website text from Internet Archive
  Wayback Machine captures made on or before each case date, included in short form for research
  and evaluation. Rights in website text remain with its owners.

Every application in the data is constructed for the benchmark; some contain deliberately altered
details. Nothing in the data implies wrongdoing by any named company or person beyond existing
public records.
